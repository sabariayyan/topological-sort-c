Theoretical Foundation

Core Concepts at a Glance

Read Full Tutorial 📖

1. Directed Acyclic Graph (DAG)

A directed graph with no directed cycles. If a cycle exists ($u \to v \to \dots \to u$), no vertex in the cycle can be resolved first because each vertex is a prerequisite for another.

2. In-degree Reduction (Kahn's Method)

The in-degree of a vertex is the count of incoming edges. Kahn’s algorithm repeatedly removes vertices with in-degree 0, adding them to the linear order and decrementing the in-degrees of their neighbors.

3. DFS Post-Order Stack Method

Performs Depth-First Search. When all outgoing neighbors of a vertex have been completely visited, the vertex is pushed onto a stack. Popping the stack gives the topological order.

4. Optimal Time & Space Complexity

Using an Adjacency List, Kahn’s Algorithm operates in O(V + E) time and O(V) auxiliary space, where V is the number of vertices and E is the number of edges.
