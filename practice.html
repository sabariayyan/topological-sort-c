A Directed Acyclic Graph (DAG) is a directed graph that contains no directed cycles. In other words, for any vertex $v$, there is no directed path starting and ending at $v$. DAGs are fundamental in computer science because they represent prerequisite structures, scheduling constraints, and dependency trees.
The in-degree of a vertex in a directed graph is the total number of incoming directed edges terminating at that vertex. In a dependency graph, a vertex's in-degree represents the number of prerequisite tasks that must be completed before this vertex can be executed. A vertex with an in-degree of 0 has no prerequisites.
Topological sorting is a linear ordering of vertices of a Directed Acyclic Graph (DAG) such that for every directed edge $u \to v$, vertex $u$ appears before vertex $v$ in the ordering. It provides a valid sequential execution order that respects all dependencies.
Topological sorting is impossible for graphs containing cycles (e.g., $A \to B \to C \to A$) because no linear order can satisfy circular dependencies simultaneously ($A$ must precede $B$, $B$ must precede $C$, but $C$ must precede $A$). Cycle detection is required to verify that the graph is indeed a DAG and to report errors if deadlocks or circular dependencies occur.
Kahn’s Algorithm is a BFS-based algorithm for topological sorting:
  1. Calculate the in-degree of every vertex in the graph.
  2. Enqueue all vertices with in-degree 0 into a FIFO queue.
  3. While the queue is not empty, dequeue vertex $u$ and append it to the topological order.
  4. Decrement the in-degrees of all neighbors $v$ of $u$. If any neighbor's in-degree drops to 0, push it into the queue.
  5. If the count of ordered vertices equals $V$, sorting succeeds; otherwise, a cycle exists.
For a graph with $V$ vertices and $E$ edges using an Adjacency List representation:
  • Time Complexity: $O(V + E)$ because each vertex is enqueued/visited once ($O(V)$) and each directed edge is inspected once ($O(E)$).
  • Space Complexity: $O(V)$ auxiliary space for the in-degree array, queue/stack, and result array.
  1. Build Systems & Compilation: Tools like Make, CMake, and gcc use topological sort to resolve header file and object file dependencies, ensuring modules are compiled in the correct order.
  2. Course Prerequisite Scheduling: Academic degree planners order prerequisite university courses so students take foundational classes (e.g. Math 1, CS 101) before advanced electives (e.g. Machine Learning).
